# 招收公告｜山东大学齐鲁医院普外科杨其峰教授课题组统招博士后

> 更新时间：2026-09-11 (UTC+8)

山东大学齐鲁医院普外科杨其峰教授课题组因科研工作需要，现面向国内外公开招收统招博士后2名。

**杨其峰教授简介：**

杨其峰，国家二级教授、山东大学特聘教授、主任医师、博士生导师，国家级高层次人才、泰山学者特聘专家，美国新泽西州癌症中心客座教授，现任山东大学齐鲁医院乳腺外科行政主任。全国乳腺癌专家学术影响力百强排名第3位，入选2020年中国高被引学者。承担科研项目16项，其中国家重点研发计划课题2项、国家自然科学基金面上项目7项、省部级课题7项，在Nat Cell Biol、J Clin Invest、J Clin Oncol、Mol Cancer、Clin Cancer Res、Cell Death Differ等国际知名杂志发表SCI论文240余篇，影响因子累计1000分，被SCI论文引用6000余次。

**课题组简介：**

杨其峰教授课题组致力于乳腺癌的转化医学研究，从免疫、信息生物学、干细胞等领域入手，通过体外细胞学实验和体内动物模型探讨乳腺癌耐药转移的分子调控机制，并与临床乳腺癌患者信息进行系统集成，勾画耐药转移的调控网络并确立关键分子。研究成果将为乳腺癌新药开发提供关键分子靶标，也将为病情监测和预后分析提供新型分子标志物。课题组主持国家重点研发计划、国家自然科学基金、山东省自然科学基金、山东省重点研发计划、其他省部级课题等共计40余项。

**一、招聘要求**

1. 政治素质好，遵纪守法，身心健康，学风端正。

2. 即将取得博士学位或取得博士学位一般不超过3年；肿瘤生物学、细胞生物学、生物化学、免疫学等相关专业；年龄一般不超过35周岁。

3. 具有良好的科研基础和发展潜力，有同行认可的研究成果，有志于在课题组既有研究方向上继续深入。

4. 有创新意识和良好的团队协作精神，工作勤奋主动，严谨负责，有创新意识，能独立或指导研究生开展相关实验。

5. 具有耐药转移、免疫、自噬、信息生物学、干细胞等方面的研究经历者优先。

**二、薪酬待遇**

1. 待遇从优，享受山东大学齐鲁医院博士后待遇，基础年薪30万起，高水平博士后35-40万；

2. 支持申请各类博士后基金和项目，享受医院职工同等的论文、项目等学术奖励；

3. 可申领博士后租房补贴；

4. 提供优良的实验科研条件。

**三、应聘材料**

1. 个人简历（包括学习和工作经历、已发表的科研论文列表、论文全文、联系方式等）；

2. 学历学位证书／资格证书／获奖证书复印件；

3. 进站后科研/工作设想；

4. 推荐信2-3封，其中包括博士导师推荐信。

**四、联系方式**

有意者请将应聘材料发至邮箱zhaowenjing0911@ 163.com，注明“博士后应聘”。经面试考核后择优录用。应聘材料将予以保密，恕不退还。应聘信息在职位满额前一直有效。
