# 降调期间生活、用药指导

> 更新时间：2026-09-11 (UTC+8)

生活指导：
- 用药期间放松心情，保证充足的睡眠，避免熬夜，尽量避免感冒、发烧、腹泻，建议不要化妆、涂指甲油等有刺激性气味的化妆品，如有身体不适，请及时到相关科室就诊。
- 降调节过程中，有自然妊娠可能，降调节药物有可能影响激素分泌从而增加孕早期阴道出血、胚胎停育风险，建议工具避孕。
- 就诊流程：B超检查后，下次复诊请按照以下流程完成：签到（微信小程序--挂号签到/自助机--签到取号）→缴费（微信小程序--检查缴费/自助机--自助缴费）→等候B超室呼叫完成B超检查→缴药费（微信小程序--缴药费/自助机--自助缴费）→一楼药房取药→药物注射（后宰门院区一楼注射室/曲江院区一楼妇产科急诊）。
用药指导：
- 每天相对固定时间注射。
- 降调药分为两种：
短效降调：曲普瑞林（取药前，请自备冷藏包）：2-8℃冷藏，中途来月经属于正常现象。
长效降调：达菲林/亮丙瑞林，期间有无月经均为正常现象，若出血量大于月经量及时复诊。
- 每天遵医嘱用药，不能自行停药或减药（有特殊情况及时和医生沟通）。
- 拿到处方，请到药房取药，注射室注射（后宰门院区一楼注射室；曲江院区一楼妇产科急诊），第一针建议您在本院注射，剩余药物可在当地注射。
- 采血早7:30开始，B超按排队号等候呼叫，若超过预约时间无法签到，请到护士站重新约号（阴道B超不需要憋尿）。
